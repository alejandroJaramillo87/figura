# Agent configuration

Claude Code configuration for this repository: the agents, commands and permission settings
every session here uses. What each one is for is in
[../docs/agents/tooling.md](../docs/agents/tooling.md).

- `agents/`: agent definitions, one markdown file each.
- `commands/`: slash commands.
- `settings.json`: permissions shared by every session in this repository.

Every agent follows `../.styles/DIAGRAM_STYLE.md` when it touches a diagram, a template or
`shared/`.
